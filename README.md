# Ekansh Jain Portfolio

The source for Ekansh Jain's original personal portfolio website.

## Features

- Responsive portfolio and project showcase
- Animated landing sections, filtering, carousels, and lightbox interactions
- Resume and contact information
- Express endpoint for contact submissions
- MongoDB model for persisted contact messages

## Stack

- HTML, CSS, JavaScript, Bootstrap, and jQuery
- Express, Node.js, and MongoDB

## Local development

    npm install
    npm run dev

The static site entry point is index.html. Configure the MongoDB and server environment values before using the contact backend.

## Status

This is the archived first-generation portfolio, developed in 2020. It remains useful as a record of early frontend, design, and full-stack work.
